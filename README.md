# WHY ME — Insights & Mentor Match

Відкрийте `index.html` у браузері. Файли `style.css`, `script.js` та `assets/` повинні бути поруч.

## Що нового
- Після 12 запитань автоматично ранжуються 12 демонстраційних менторів за інтересами, обраними професіями й виконаними мініпробами.
- На сторінці результатів: інтерактивна пелюсткова діаграма, кругова діаграма з клікабельними напрямами, порівняння професій і перегляд відповідей.
- Рекомендовані ментори з поясненням збігу з'являються на сторінці результатів та в особистому просторі.
- Фільтр менторів за форматом і містом, демонстраційний запис, вибір п'яти професій і 3D-перевертання карток збережено.
- Збереження стану у localStorage браузера. Можна почати заново в особистому кабінеті.

## Важливо
Всі імена менторів, дати, календар, фото та зустрічі — демонстраційні. Це не справжнє бронювання. Результати — дослідницькі підказки, а не валідований психометричний тест.
Для реального підбору живих менторів знадобляться їхня згода, перевірені анкети, backend/база даних і справжня система бронювань.
